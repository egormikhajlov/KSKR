# FlowPrep 0.1

Начальная программа к курсовому проекту Михайлова Егора Вячеславовича,
группа ИТП-41. Тема: определение геометрических параметров заслонки
для перенаправления ламинарного течения газового потока.

## Запуск

Нужен Python 3.10 или новее с Tcl/Tk. Сторонних пакетов нет.
На Windows открыть `Запуск.bat`; из терминала выполнить `python flowprep.py`.
В PyCharm открыть эту папку, выбрать Python и запустить `flowprep.py`.

Программа проверяет геометрию прямоугольной поворотной заслонки в плоском
канале, рассчитывает аналитический эталон для **канала без заслонки**,
сохраняет настройки и готовит серию из 15 вариантов. Значения по умолчанию
демонстрационные: в задании нет размеров канала, свойств газа и скорости.

Реализована подготовка к дальнейшему исследованию. Поля скорости и давления
при наличии заслонки не вычисляются. Связь с ANSYS ещё не реализована.
Файлы КОМПАС и расчёты ANSYS в эту версию не входят.

## Командная строка

```text
python flowprep.py reference
python flowprep.py prepare --out export
python flowprep.py prepare --config export/settings.json --out export2 --angles 15,30,45 --chords 0.012,0.020
python -m unittest discover -s tests -v
```

## Расчётная модель

Канал двумерный; все расходы и потоки импульса приведены к единице ширины.
Для эталона заданы стационарное несжимаемое развитое течение ньютоновской
жидкости и прилипание к стенкам. На входе — параболический профиль.
Гидравлический диаметр бесконечно широкого канала `Dh = 2H`.

```text
u(y) = 6 U (y/H) (1-y/H)
Re = rho U (2H) / mu
delta_p = 12 mu U L / H²
tau_wall = 6 mu U / H
f_Darcy = 96 / Re
```

Это точное решение идеализированного пустого канала. Его перепад давления
не описывает потери на заслонке и не используется для выбора её угла.
Оценка входного участка `0.05 Re Dh` ориентировочная; равномерный профиль
в коротком канале не соответствует предположению развитого течения.
Здесь задаётся уже развитый профиль. Низкое Re само по себе не исключает
локальную нестационарность около препятствия.

## Состав экспорта

- `settings.json`: исходные данные в СИ.
- `reference.json`, `reference_profile.csv`: аналитический эталон.
- `geometry.svg`: схема, не чертёж КОМПАС и не поле CFD.
- `cases.csv`, `manifest.json`: допустимые варианты, отклонения и статус.
- `case_.../case.json`: параметры, вершины, граничные условия.
- `case_.../geometry.svg`: схема отдельного варианта.
- `ansys_results_template.csv`: пустая форма для будущего реального экспорта.

CSV сохраняются с UTF-8 BOM и запятой как разделителем. В Excel при
необходимости используйте импорт текста с явным выбором разделителя.
JSON сохраняются в UTF-8. ID зависит от всех параметров, включая допуски;
для другой серии используйте её собственный манифест.

## Дальнейший импорт

После получения настоящих результатов решателя заполнить CSV:

| Поле | Смысл |
|---|---|
| `case_id` | ID из манифеста этой серии |
| `converged` | `true`, `1` или `yes` после проверки сходимости |
| `mass_in_kg_s_m` | Положительный модуль массового расхода на входе, кг/(с·м) |
| `mass_out_kg_s_m` | Положительный модуль массового расхода на выходе, кг/(с·м) |
| `momentum_x_n_m` | Интеграл `rho*ux² dy` на контрольном сечении, Н/м |
| `momentum_y_n_m` | Интеграл `rho*ux*uy dy` там же, Н/м |
| `total_pressure_in_pa` | Среднее полное давление на входе, взвешенное по массовому расходу, Па |
| `total_pressure_out_pa` | Такое же среднее на выходе, Па |
| `mesh_cells` | Число ячеек расчётной сетки |
| `solver` | Название и версия решателя |

Для несжимаемой модели `p_total = p + rho*(ux²+uy²)/2`.
При обратном течении на контрольном сечении или входе/выходе сначала
проверить корректность интегральных отчётов и положение сечений:
автоматической диагностики обратных течений по одному CSV нет.

```text
python flowprep.py import-results results.csv --manifest export/manifest.json --out comparison.json
```

Программа проверяет известность и уникальность ID, конечность чисел,
сходимость, баланс массы, соответствие заданному расходу и знак потерь.
Незаполненные строки отклоняются; отсутствующие ID перечисляются.
Угол потока вычисляется как `atan2(momentum_y, momentum_x)`.
Среди вариантов в допуске целевого угла выбирается минимальная потеря
полного давления. Это выбор среди импортированных вариантов, а не
доказательство глобального оптимума. Исследование сеточной независимости
и физическая валидация остаются отдельными обязательными шагами.
